# Finder、资源管理器与系统拼音候选版验收

请只使用临时样本。记录候选提交、系统版本、输入源、实选词以及失败的第一步。两端各自通过才放行 main。自动化派发 composition 事件、粘贴汉字、直接把文件路径传给可执行文件都不能替代本表。

## Mac：需要在交互式桌面单独执行

1. 下载对应候选提交的 LightMark-macOS 构建产物，解开外层包，再解开 LightMark-mac.zip。核对内层 zip 的 SHA-256 与构建日志相同。使用测试账户；若系统阻止启动，记录提示并停下，勿关闭系统防护。
2. 在测试目录新建“甲 笔记.md”和“乙 笔记.markdown”，正文各写“甲原文”和“乙原文”。在 Finder 的“显示简介 → 打开方式”选择此候选应用；如需更改全部，请仅在测试账户操作。检查文件没有隐藏的 .txt 后缀。
3. 用 ⌘Q 完全退出。在 Finder 双击甲，核对标题和正文。在甲末尾写一个星号但不保存，双击乙，再双击甲；应回到同一窗口的甲标签，星号仍在，没有重复标签。保存并完全退出。交换甲乙顺序再测一遍。这覆盖两种扩展名各自的冷启动和热启动。
4. 选择系统“简体拼音”。在可视化模式下输入 nihao，确认候选框出现，使用数字键或空格选择一个中文词，记下实选的词。按 ⌘S，以另一只读查看器或终端 cat 核对磁盘上只有一份该词，没有残留 nihao。
5. 切到源码，确认上一词还在。在末尾用拼音输入 shijie，选词并按 ⌘Z：应只撤销第二个词，不能删掉原文。再次组字选词、保存，切回可视化再退出重开，核对两词与磁盘一致。
6. 单独试未确认候选：打开候选框时按保存，然后确认或取消；再在候选框打开时点击模式切换。核对确认内容仅出现一次，取消内容不落盘，状态栏不能在磁盘与正文不一致时声称“已保存”。记录输入法实际处理快捷键的方式。

## Windows

在隔离的 Windows 用户中安装同一提交的 NSIS 包，按上面的 2–6 步，将 Finder 换为资源管理器、⌘S/⌘Z 换为 Ctrl+S/Ctrl+Z、输入源换为微软拼音中文模式。通过“打开方式”设置默认时不要更改日常用户的偏好。
