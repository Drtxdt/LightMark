# 500MiB 后端实施与 release 压力证据

记录时间：2026-10-24。此记录仅覆盖 Rust 后端，不替代 WebView、真实 IME、安装、桌面导出或 UI 呈现验收。

## 实现边界

- 磁盘快照按约 64KiB 保存稀疏字节、UTF-16、换行统计；持久区段树和历史共享不可变根。编辑增量写入并同步私有 journal；全局替换流写候选快照，版本校验后原子提交一个可撤销根。
- `read_file_range` 正文响应硬上限 256KiB。超长行可从中部读取，合法 EOF sentinel 返回规范化坐标；窗口回退误落 UTF-16 surrogate 中部时，仅读取起点向前取字符边界。编辑和导出坐标仍严格校验。
- 编辑和历史具有 operationId 回执与 payload 校验；相同重试不二次提交，不同内容重用同 ID 拒绝。保存保留旧快照与历史引用。超过 500MiB 的只读策略按会话打开时大小决定，避免恰好 500MiB 的文档增长后锁死撤销。
- 查找和替换使用后台 job；literal 扫描、文件 IO 与每次匹配可取消。完整 regex 扫描的单次引擎调用不能即时抢占，取消会在下一检查点生效。搜索结果有数量和文本上限。regex 零宽匹配可查找、替换和撤销。
- 无人使用的旧全行 search/replace IPC 已移出生产注册，仅保留测试实现。旧 `read_file_chunk` 超过 256KiB 会拒绝并要求使用部分行范围接口。
- `get_file_info` 已移除整行 `read_until` 与完整偏移数组，改为固定 64KiB 流式计数。大文件 IO 的 Tauri 命令在后台执行，避免同步 IPC 占用 UI 线程。

## 本轮新增缺陷回归

1. 打开入口仍物化巨行/全部行偏移：固定缓冲读取，覆盖空文档、混合 EOL、跨读取 CRLF 和 50MiB 短行访问上限。
2. EOF 空窗口连续输入的第二次坐标失效：规范范围起点，覆盖 emoji 后连续两次 append；真正越界和编辑 surrogate 半单位仍拒绝。
3. 无 BOM 文档通过替换插入 BOM 后丢字节：先跑红测试确认，修复候选快照剥离的新增 BOM 作为 delta 叶保留。
4. `start_line > 0` 时每个搜索命中重新求行列：过滤起点转换一次，结果上限达到后不再为纯计数物化坐标。
5. regex 零宽匹配被忽略：覆盖 `^`、BOM/CRLF、搜索起点/上限、替换和撤销。
6. 跨窗口导航使用粗略窗口跳步：新增版本绑定的 previous/next/clamp 坐标接口，覆盖 Unicode scalar、CRLF、短行、EOF 和 500MiB 虚拟文档的局部访问预算。
7. 替换完成回执随 60s job 缓存过期变成未知：会话保留小回执，过期后按原 session/jobId/启动 revision 查询；旧结果不重复执行，后续输入不被回退。search 大结果仍按 TTL 释放。
