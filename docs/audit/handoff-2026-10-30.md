## 本批修复

1. `appStore.ts` 保留 raw tab 作为保存/大文件回执的稳定身份，通过 Vue 规范代理发布 dirty、路径、名称、revision 和 pending 等字段。普通保存、另存为、后台标签和大文件均有真实 Vue effect 回归。最终原生七个内容场景同时验证磁盘正确和标签 DOM 清除脏标记。
2. `MathNodes.ts` 的行内/块级公式提交允许完整 `Node.eq` 的不可变根重建，仍拒绝不同 attrs、marks、type 或内容。真实 NodeView 红测试先复现错误，修复后通过；位置、会话和其他冲突保护保留。
3. 公式评估改为每个 editor 仅缓存当前 doc/编号模式的整份派生索引；设置/工具刷新统一失效。此前 `WeakMap<doc,evaluation>` 的键被撤销历史强持有，实际 2460 公式索引含约 730 万字符 KaTeX HTML，连续编辑会保留大量历史索引。旧失败在第 262 次提交时 renderer 退出；第 100/200 次后堆内存约 2.26/3.30GB。修复后专门压力测试 300/300、三轮精确 undo/redo/reset 通过，自然 GC 下第 100/200/300 次后的堆约 133/252/212MB；最终完整运行对应约 182/199/101MB，未提高堆上限或强制 GC。
4. 新增独立 NodeView 保存夹具：Front Matter、HTML、脚注、公式、Mermaid、合法 TOC、TOC 转段落，七类各实际写盘两次，检查正文、焦点、选区、pending 和标签 DOM。TOC 转段落记录合法的控制框退役与焦点回正文例外；主夹具和原历史保留。
5. 性能探针加入实际 mounted 公式编辑框的 CDP Ctrl+Enter、精确 TeX/关闭编辑框/KaTeX 反馈；首个失败后保留失败并停止该轮重复超时。诊断压力模式显式无正式比较资格，完整采样要求不变。修正发布验收脚本中不存在的 Ctrl+O 指引为 Open File 按钮。
