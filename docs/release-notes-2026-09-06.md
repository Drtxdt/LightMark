# LightMark 修复与体验升级（2026-09-06）

本版本基于 `d0bf357`，重点处理编辑安全、公式焦点、源码保真和基础视觉一致性。

## 已完成

- 公式编辑增加统一的待提交刷新边界；保存、切换、导出和草稿快照前会等待组合输入结束并提交公式源码。
- 行内公式退出后恢复正文选区；支持按点击侧进入首尾、Enter 提交、两次 Escape 语义和边界方向键离开。
- 块公式保持多行 Enter，使用 Ctrl/Command+Enter 提交退出，编辑 DOM 在输入期间保持稳定。
- 未编辑文档保存直接复用原始 Markdown；局部编辑按顶层源码范围拼接，保留未编辑区域的 BOM、换行、空白和分隔符。
- 源码映射失效时停止保存并保留原文件与编辑缓冲，不再静默整篇规范化。
- 工具栏接通 3×3 表格插入入口。
- 状态栏区分未保存、保存中、已保存和保存失败。
- 浅深主题改为中性灰与低饱和蓝语义色，并补充 Windows 中文字体回退；原图标和昼夜切换组件保持不变。
- 新增行为验收矩阵和源码保真回归检查。

## 后续编辑状态机修复

- 对称 Markdown 标记展开时保留正文格式，不再先进入不可编辑装饰态、再退化为纯文本。
- 方向键从标记左侧退出后可第一次右移即重新进入，不再弹回或需要二次按键。
- 删除多字符分隔符中的任一字符会移除整组分隔符并取消对应格式；嵌套的其他格式保留。
- 标题在 `#` 左侧输入字符会暂时转为段落，删除该字符后立即恢复标题渲染。
- 展开与收起属于展示 transaction，不设置脏状态、不增加内容 revision、不进入撤销历史；快照前统一收起。

## 尚需发布前人工验收

当前执行环境无法控制原生 Windows 应用，因此真实 WebView2、中文输入法、100%/125%/150% 缩放、导出排版、30 分钟稳定性和性能 P95 尚未实测。这些项目继续以“未验证”记录在[验收矩阵](./acceptance-matrix.md)，不能仅凭自动化结果标记为通过。

## 已知限制

- 超过 5 MB 的文档仍使用既有大文件策略。
- Pandoc 输出取决于本机 Pandoc 与相关排版依赖。
- 工作区文件移动/重命名尚未完成所有 Markdown、Wiki 与附件引用的原子更新闭环。
- 非标准组合语法若无法建立安全源码映射，所见即所得保存会失败关闭；请切换到源码模式恢复或另存副本。
