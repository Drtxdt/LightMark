# LightMark Markdown 编辑器差距与超越路线

> 更新时间：2026-07-29
> 范围：本文只追踪 LightMark 当前仍未完整支持、或相对 Typora / Obsidian / Notion / Bear 明显较弱的能力。已经落地的功能不再作为 gap 追踪。

## 已不再列为差距的能力

LightMark 当前已经支持或基本支持以下能力，因此本文不再重复追踪：

- 所见即所得编辑、源代码模式、模式切换时编辑区同步与滚动定位。
- 查找替换面板、顶部工具栏、设置界面、UI 弹窗。
- 内联/块级 HTML、HTML 安全过滤、GitHub 风格警示框。
- 公式、Mermaid、代码块语言控件、代码高亮基础能力。
- 图片粘贴/拖入、图片 Markdown 即时渲染、图片点击编辑。
- PDF / HTML / PNG / Pandoc 多格式导出，且导出尽量贴近编辑区样式。
- 主题切换、原生窗口标题/标题栏配色适配、无控制台打包。
- 自动保存、崩溃草稿恢复、多文档标签页基础工作流。
- 普通文件保存前冲突检测、保存时删除路径保护、临时文件安全写入。
- 外部文件变更非阻塞提示、删除提示、标签状态标记。
- 标签拖拽排序、关闭其他/关闭全部、最近关闭标签恢复。
- 快速打开文件 `Ctrl+P`、最近文件回退、前往指定行 MVP、文件级前进/后退导航栈。
- 文件可靠性后续 MVP：冲突副本、轻量 diff 预览、重命名/移动候选重新绑定。
- 原生文件 watcher、`Ctrl+Shift+O` 标题跳转弹窗、标题/搜索跳转入导航栈。
- Wiki Links / Backlinks MVP：`[[page]]` 渲染、点击跳转/创建、源码模式轻量补全、反链面板。
- WYSIWYG Wiki Links 补全与别名：所见即所得 `[[` 候选、Front Matter `alias` / `aliases`、统一索引、跳转与反链匹配；候选支持别名和相对路径区分重名文档。
- 工作区知识索引：递归监听 Markdown 文件，统一维护 Wiki Links、aliases、正文/YAML tags 与可搜索片段；“知识”侧栏集中提供反链、未链接提及和标签浏览，`Ctrl+P` 支持 aliases/tags 元数据搜索。
- Typora 式输入规则第一阶段：源码/WYSIWYG 自动配对与选区包裹、列表续行与退出、有序编号、上下文相关的 Tab / Shift+Tab。
- 输入规则回归修复：反引号不再自动补右侧，连续三个反引号可稳定生成围栏；代码块选区按 Tab / Shift+Tab 会逐行缩进/反缩进，不再覆盖选中文字。
- Markdown 保守格式化第一阶段：结构保护、列表缩进、空行、表格与 Front Matter 边界规范化；提供行级 diff、取消/应用、双编辑器单次事务和光标映射。
- 状态栏章节面包屑：普通文档跟随源码/WYSIWYG 光标，大文件跟随视口可见行；支持层级路径、分屏活动栏、点击跳转和窄窗口收纳。
- 光标与滚动位置恢复：普通文档标签切换、会话恢复、后退/前进导航恢复到最近编辑视角。
- 应用内左右分屏独立编辑 MVP：底层 tab registry 共享，但每栏拥有独立标签条、独立 active tab、独立编辑上下文和独立模式切换；单标签启用分屏时会为右侧创建独立未命名标签，避免左右共用同一文档。
- 数据完整性与恢复回归修复：表格共享解析器保护转义管道和可变反引号代码，Front Matter 在 WYSIWYG 往返中原文保留，反链按统一 Wiki 索引解析；源码/WYSIWYG 格式化均可单次撤销。
- 完整会话恢复：工作区、两栏标签顺序、活动文件、活动栏、分屏比例、编辑模式、光标和滚动位置均以稳定路径键恢复，旧配置保持兼容。
- 自包含导出可靠性：HTML/PDF/PNG 统一内联本地图片与公式字体；PNG 改由桌面端无头浏览器分片渲染和 Rust 合并，PDF 对超大图片使用打印分页约束。
- 全功能复测缺陷闭环：WYSIWYG 格式化使用精确 Markdown 快照撤销/重做，模式切换不再被动标脏；命令浮层、偏好设置和嵌套确认框统一自动聚焦、顶层 Esc、焦点约束、恢复与互斥；偏好设置只陈述真实能力。
- Pandoc 本地 SVG 兼容：PDF 导出在应用内部将本地 SVG 栅格化，无需额外安装 `rsvg-convert`，并在导出后清理中间资源。
- 数学公式专项第一阶段：编辑器、预览与原生导出共享 Typora/Pandoc 行内边界规则，货币、转义、代码、Front Matter 和原始 HTML 不再误判；KaTeX 错误可在 WYSIWYG 与源码模式就地查看和定位，转义美元、可变反引号代码及 HTML 保护区在编辑其他公式后仍可无损往返。
- 数学公式专项第二阶段：`\def` / `\newcommand` 等宏按文档顺序和标签/分栏隔离生效，纯定义块可见可编辑；KaTeX mhchem、动态宏补全、原生导出及 Pandoc PDF/LaTeX 链路同步接通。
- 数学公式专项第三阶段：文档级公式索引支持 `\label` / `\tag` / `\ref`、前向与后向引用、三种块级编号策略、WYSIWYG/源码点击导航及“前往公式”浮层；原生与 Pandoc 导出保持编号和引用一致。
- 数学工具与正式 CLI：公式节点支持复制原始 Markdown、KaTeX HTML、MathML 和主动刷新；导出菜单按文档特性展示兼容、降级或阻断状态；`lightmark-cli` 提供 check / formats / export、结构化 JSON、固定退出码和全部桌面导出格式。

### 2.4 数学公式与学术写作

LightMark 已经具备基础数学公式能力：行内/块级公式、KaTeX 渲染、公式源码点击编辑、代码区保护、`\(...\)` / `\[...\]` / 常见 equation/align 环境导入渲染、LaTeX 命令补全，以及 PDF/HTML 导出中的公式字体修复。下面只列 Typora 数学页中仍明显缺失或需要打磨的部分。

| ✓ | 任务 | 说明 |
|---|------|------|
| ✓ | Pandoc 风格行内公式规则 | 编辑器、预览与原生导出共享严格边界；已覆盖货币、转义、中文相邻、代码、Front Matter、HTML 与原始分隔符往返 |
| | Legacy inline math 兼容模式 | Typora 可切换旧版 `$...$` 解析规则；LightMark 可在设置中提供兼容开关，用于打开老文档 |
| ✓ | 用户自定义宏 | `\def`、`\gdef`、`\newcommand`、`\renewcommand` 和 `\providecommand` 按文档顺序生效；错误定义不污染后续公式，标签与分屏上下文隔离 |
| | Physics package | Typora 可启用 physics 包；LightMark 需要评估 KaTeX 宏实现或迁移 MathJax 渲染后支持 `\qty`、`\dv`、`\pdv` 等 |
| ✓ | mhchem 化学公式 | KaTeX mhchem 默认启用，支持 `\ce{H2O}`、反应式、同位素、嵌套数学和 `\pu{}`，并覆盖原生导出及 Pandoc PDF/LaTeX |
| ✓ | 公式标签与引用 | 支持平衡解析 `\label{}`、`\tag{}`、`\ref{}`、前向/后向引用、重复和缺失诊断，并在编辑区、预览与导出中一致 |
| ✓ | 公式自动编号 | 支持关闭编号、AMS 公式块、所有块级公式三种策略；手写 tag 覆盖显示值但保持后续计数稳定 |
| ✓ | 数学工具菜单 | 公式悬停/聚焦工具条可复制原始 Markdown、KaTeX HTML 和 MathML，并可刷新文档全部公式；错误公式禁用不可用的复制目标 |
| | 换行兼容选项 | Typora 提供 “Apply Line Break at \\”；LightMark 可选择自动包裹 `\displaylines{}` 或给出修复提示 |
| ✓ | 数学错误诊断 | WYSIWYG 就地显示可读错误并点击编辑；源码模式使用波浪线、悬停详情和点击定位，导出安全降级为带提示的原始源码 |
| ✓ | 导出兼容矩阵 | 原生 HTML/PDF/PNG 与 Pandoc PDF/LaTeX 完整支持当前数学链；Office/EPUB 与文本格式按实测显示降级，缺失引用在导出前阻断 |
